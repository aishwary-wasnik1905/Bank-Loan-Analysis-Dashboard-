# 🏦 Bank Loan Analysis Dashboard

An interactive **Power BI dashboard** built to analyze bank loan performance using **38,577 loan records**. The project focuses on data cleaning, KPI validation using SQL, and creating insightful visualizations to support data-driven decision-making.

---

## 📌 Project Overview

This project analyzes historical bank loan data to uncover trends in loan applications, funded amounts, repayments, customer demographics, and loan quality. SQL was used to validate key business metrics before developing the dashboard in Power BI.

---

## 📊 Dashboard Features

- KPI Cards
  - Total Loan Applications
  - Total Funded Amount
  - Total Amount Received
  - Average Interest Rate
  - Average DTI

- Loan Performance Analysis
  - Good vs Bad Loans
  - Loan Status Breakdown
  - Monthly Loan Trends

- Customer Analysis
  - Home Ownership
  - Employee Length
  - Loan Purpose
  - State-wise Analysis
  - Loan Term Analysis

- Interactive Filters
  - State
  - Grade
  - Loan Status
  - Purpose
